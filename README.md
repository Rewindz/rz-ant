# RZ-ANT

*rz-ant* is a thrown together [Langton's Ant](https://en.wikipedia.org/wiki/Langton%27s_ant) renderer.

The code is a bit messy

*IT REQURIES A COMPILER WITH '#embed' SUPPORT AT THE MOMENT*

### Dependencies

- GLFW3
- Dear ImGui
