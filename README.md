# RZ-ANT

*rz-ant* is a thrown together [Langton's Ant](https://en.wikipedia.org/wiki/Langton%27s_ant) renderer.

The code is a bit messy

*IT REQURIES A COMPILER WITH '#embed' SUPPORT AT THE MOMENT*

![Langton's Ant Version 1](screenshots/v1.png)

### Controls

- Left Click + Drag to pan
- Right Click to toggle the menu
- Scroll Wheel to zoom in, out

### Dependencies

- GLFW3
- Dear ImGui

<sub>*The dependencies will be retrieved through CMake*</sub>
